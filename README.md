# Скрипты для DaVinci Resolve

## Автонарезка по тишине

`resolve_autocut.py` анализирует отдельный аудиофайл или первую встроенную аудиодорожку видео и собирает монтажную линию из звучащих фрагментов. Видео и звук нарезаются вместе. Таймлайн ссылается на исходный файл, его можно редактировать в Resolve. Скрипт рассчитан на видео с постоянной частотой кадров.

### Запуск в Windows

1. Установи [Python](https://www.python.org/downloads/windows/) и скачай [FFmpeg](https://ffmpeg.org/download.html#build-windows).
2. Положи `ffmpeg.exe` и `ffprobe.exe` рядом со скриптом или добавь каталог с ними в `PATH`.
3. Запусти `python resolve_autocut.py`, выбери видео, при необходимости выбери отдельное аудио и нажми **Собрать таймлайн**.
4. В DaVinci Resolve открой **File → Import → Timeline** и выбери сохранённый `.fcpxml`. Если Resolve предложит найти исходник, укажи папку с видео.

Для отдельных файлов скрипт совмещает их по началу. Если запись с микрофона началась раньше или позже видео, сначала подровняй исходники. При выборе отдельного аудио на таймлайн попадает звук из этого файла.

По умолчанию скрипт вырезает паузы тише −35 дБ длительностью от 0,65 с, сохраняя по 0,12 с вокруг звучащих фрагментов. При постоянном шуме или фоновой музыке результат зависит от порога громкости.

Из терминала можно запустить так:

```powershell
python resolve_autocut.py "video.mp4" --threshold -35 --min-silence 0.65 --padding 0.12
```

Монтажная линия сохранится рядом с видео как `video-autocut.fcpxml`. Для отдельной записи добавь `--audio "microphone.wav"`. Чтобы выбрать другой путь, укажи `-o "timeline.fcpxml"`.
