# Скрипты для DaVinci Resolve

## Установка в Windows

1. Скачай [ResolveScriptsSetup.exe](https://github.com/prostoodin1/DaVinci-Resolve-Scripts/releases/latest/download/ResolveScriptsSetup.exe) из релиза. Для скачивания нужен доступ к приватному репозиторию.
2. Запусти установщик. Он ищет Resolve в стандартной папке и в реестре Windows. Если путь пустой, укажи свой Resolve.exe.
3. Отметь нужные инструменты и нажми **Установить / обновить выбранные**. Полный EXE содержит Python, FFmpeg, PocketSphinx и русские и английские речевые модели. Установка и обработка медиа работают офлайн.
4. Перезапусти Resolve. В меню **Workspace → Scripts** появятся выбранные команды с префиксом **DRS**. Два инструмента нарезки сохраняют FCPXML, который открывается через **File → Import → Timeline**.

Пункты меню устанавливаются в пользовательскую папку скриптов Resolve. Установщик и рабочие файлы хранятся в %LOCALAPPDATA%\DaVinci Resolve Scripts.

### Обновления из GitHub

Установщик один. При каждом открытии он автоматически загружает catalog.json из ветки main и показывает все опубликованные инструменты и их версии. Отметь нужные и нажми **Установить / обновить выбранные**. Кнопка **Проверить GitHub** обновляет список повторно. Последний успешно полученный каталог сохраняется для работы офлайн.

Установщик может использовать сохранённый вход Git for Windows. Без Git выбери **Войти по токену** и укажи токен GitHub с правом **Contents: Read** к этому приватному репозиторию. Токен действует для текущего окна установщика. Для первой установки из встроенного каталога и запуска инструментов доступ к GitHub не требуется.

Чтобы опубликовать новый скрипт, добавь его Python-файлы и запись с уникальным id, названием, версией, entry и files в catalog.json, затем отправь изменения в main одним коммитом. Следующее открытие того же установщика покажет новый пункт. Все зависимости нового инструмента должны поддерживаться включённой средой выполнения. Новая внешняя библиотека требует обновления среды в полном EXE.

Если установлен выпуск с каталогом формата 1, один раз запусти новый полный EXE. Он обновит лаунчер, который нужен для инструментов с новыми локальными зависимостями.

Для каждого инструмента отдельно ведётся версия вида **0000-17112026**. Первые четыре цифры — порядковый номер доработки, последние восемь — дата последнего улучшения в формате ДДММГГГГ. У установщика нет номера в этом формате. Версии и состав скриптов находятся в catalog.json. При изменении общего Python-файла повышай версию каждого инструмента, в чей комплект попало изменение.

## Ручной запуск

## Автонарезка по тишине

`resolve_autocut.py` анализирует отдельный аудиофайл или первую встроенную аудиодорожку видео и собирает монтажную линию из звучащих фрагментов. Видео и звук нарезаются вместе. Таймлайн ссылается на исходный файл, его можно редактировать в Resolve. Скрипт рассчитан на видео с постоянной частотой кадров.

### Запуск в Windows

1. Установи [Python](https://www.python.org/downloads/windows/) и скачай [FFmpeg](https://ffmpeg.org/download.html#build-windows).
2. Положи `ffmpeg.exe` и `ffprobe.exe` рядом со скриптом или добавь каталог с ними в `PATH`.
3. Запусти `python resolve_autocut.py`, выбери видео, при необходимости выбери отдельное аудио и нажми **Собрать таймлайн**.
4. В DaVinci Resolve открой **File → Import → Timeline** и выбери сохранённый `.fcpxml`. Если Resolve предложит найти исходник, укажи папку с видео.

Для отдельных файлов скрипт совмещает их по началу. Если запись с микрофона началась раньше или позже видео, сначала подровняй исходники. При выборе отдельного аудио на таймлайн попадает звук из этого файла.

По умолчанию скрипт вырезает паузы тише −35 дБ длительностью от 0,65 с, сохраняя по 0,12 с вокруг звучащих фрагментов. При постоянном шуме или фоновой музыке результат зависит от порога громкости.

Из терминала можно запустить так:

```powershell
python resolve_autocut.py "video.mp4" --threshold -35 --min-silence 0.65 --padding 0.12
```

Монтажная линия сохранится рядом с видео как `video-autocut.fcpxml`. Для отдельной записи добавь `--audio "microphone.wav"`. Чтобы выбрать другой путь, укажи `-o "timeline.fcpxml"`.

## Поиск склеек по смене кадра

`resolve_scene_cuts.py` ищет резкие изменения изображения в готовом ролике. Скрипт делит видео и его встроенный звук на клипы, сохраняя всю длительность таймлайна. Подходит для видео с постоянной частотой кадров.

Для запуска держи оба Python-файла в одной папке с настроенным FFmpeg. Выполни `python resolve_scene_cuts.py`, выбери видео, настрой порог и сохрани `.fcpxml`. Импортируй результат через **File → Import → Timeline**.

```powershell
python resolve_scene_cuts.py "montage.mp4" --threshold 10 --min-shot 0.5
```

Меньший порог позволяет находить менее заметные смены кадра. Вспышки и резкое движение могут дать лишние склейки. Монтажная линия по умолчанию сохраняется рядом с видео как `montage-scenes.fcpxml`.

## Проверка экспорта

`resolve_quality_check.py` ищет чёрные участки от 0,25 секунды и статичное изображение от 2 секунд. Результат — CSV с диапазонами времени от начала видео. Намеренные затемнения и неподвижные титры тоже могут попасть в отчёт.

`python resolve_quality_check.py "export.mp4"` создаёт рядом с видео файл export-check.csv.

## Синхронизация микрофона

Выбери видео со слышимым звуком камеры и отдельную запись микрофона. Скрипт сравнит звуковые волны и создаст WAV, который можно положить на начало видеоклипа или передать в автонарезку как внешнее аудио. Анализирует первые три минуты, ищет сдвиг до ±60 секунд и сообщает о неоднозначном совпадении. Коррекция постепенного рассинхрона здесь не предусмотрена.

```powershell
python resolve_audio_sync.py "camera.mov" "microphone.wav" -o "synced.wav"
```

## Речь в субтитры и поиск фразы

**DRS - Speech to subtitles** создаёт SRT из слышимой русской или английской речи в видео либо в отдельном аудиофайле. В основе классический статистический распознаватель PocketSphinx без нейросети и облачного сервиса. Это черновые субтитры. Перед использованием проверь слова и таймкоды.

**DRS - Find phrase** находит фразу в SRT, в том числе на границе соседних реплик, и выгружает диапазоны в CSV. Работает также с готовыми SRT из других программ.

```powershell
python resolve_subtitles.py "video.mp4" --language ru -o "video.srt"
python resolve_phrase_search.py "video.srt" "сейчас покажу"
```

## Поиск повторных дублей

Открой **DRS - Find repeated takes** и выбери SRT исходной записи. CSV покажет группы похожих фраз с таймкодами и процентом сходства с фразой, взятой за образец. Скрипт сравнивает формулировки офлайн, учитывает небольшие различия и фразы, разделённые между двумя близкими репликами. По умолчанию ищет фразы от пяти слов при сходстве от 80%. Проверь дубли по видео перед выбором.

```powershell
python resolve_repeated_takes.py "recording.srt" --threshold 80 --min-words 5
```

## Сборка установщика

Для сборки нужны Python 3.13, PyInstaller, NumPy и PocketSphinx 5.1.1. Скачай исходный [архив Gyan FFmpeg Essentials 9.0.2](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2) и распакуй [русскую модель CMUSphinx 5.2](https://sourceforge.net/projects/cmusphinx/files/Acoustic%20and%20Language%20Models/Russian/cmusphinx-ru-5.2.tar.gz/download). Сохрани файл LICENSE из [каталога русской модели](https://sourceforge.net/projects/cmusphinx/files/Acoustic%20and%20Language%20Models/Russian/) в папку с распакованной моделью.

```powershell
python -m pip install pyinstaller numpy pocketsphinx==5.1.1
.\build-installer.ps1 -FFmpegArchive "ffmpeg.zip" -RussianModelDirectory "cmusphinx-ru-5.2"
```

Сборка преобразует русский языковой файл в бинарный формат PocketSphinx и включает его и сопутствующий LICENSE в установщик. Исходники FFmpeg и ссылки на источники сборки доступны в [репозитории GyanD](https://github.com/GyanD/codexffmpeg). Лицензия и README сборки FFmpeg устанавливаются вместе с FFmpeg. Для выпуска новой версии отдельного скрипта обнови его код и версию в catalog.json.
